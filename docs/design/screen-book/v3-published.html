The timing rule

15 minutes either side of every class

The school day is 9:00 AM to 7:00 PM. For every class, parents drop off in the 15 minutes before it starts and pick up in the 15 minutes after it ends. The extended day (360°+ and the Learning Center) has hours the child must be in school; after them, pickup is any time until 7:00 PM. The app works out every window from the programme's hours, so when the core team changes a programme, its windows move with it.

Six logins

One sign-in for everyone

Parents, family (grandparents, aunts, uncles), coordinators, the core team, the PRO team and the admin all sign in the same way: their email, then a 6-digit code. The account decides the area. Someone with several roles, like the owner, chooses where to start and can switch any time.

  • Invite only. Only an email the admin has added gets a code. Try any other email to see the refusal, or type a wrong code to see the error.
  • Demo code 246810. One real input drawn as six boxes, so iPhone fills the code straight from Mail.
  • Several roles: the owner's account (Admin, Core team, Coordinator) chooses an area first. Parents and family see a short privacy notice once.
  • Admin is only Ankit Singh and Aditya Tapadia. Other staff are shown by role for now: Core team, Front desk and Coordinators 1 to 4.

Buttons

Solid colour sitting on a darker lip, like a real key. Hover deepens the colour. Press sinks the button onto its lip. No gradients, no glows, no shine. One main button per screen, always Jumpstart blue, and every target at least 44 points tall.

  • Corners 16 px: friendly, not a pill
  • Press moves down 3 px and the lip shrinks to 1 px, in 60 ms
